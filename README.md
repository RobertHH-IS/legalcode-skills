# Legalcode Skills

The canonical Legalcode skills repository is **[legalcode-md/skills](https://github.com/legalcode-md/skills)**.

Use the organization-owned repository for the current 250-skill catalogue and future updates:

```sh
npx skills add legalcode-md/skills --list --full-depth
npx skills add legalcode-md/skills --skill legalcode-contract-review --full-depth
```

Browse the [complete catalogue](https://github.com/legalcode-md/skills/blob/main/CATALOG.md).

This personal repository is a legacy copy. The September 2026 expansion has been published to the canonical Legalcode repository.
